# 입문 트랙 재검토 — 첫걸음과 4단계는 무엇이 다른가

「글쓰기 첫걸음」이 4단계와 무엇이 다른지 알기 어렵다는 지적에서 시작해,
여덟 종의 **도착점(학생이 마지막에 실제로 산출하는 것)**을 나란히 놓고 확인했다.

## 확인한 것

| 워크시트 | 마지막 쪽 | 학생이 쓰는 것 |
|---|---|---|
| 첫걸음 (입문 1권) | 소제목을 갖춘 글 | 서론 · 본론① · 본론② · 결론 — **네 문단** (한국어) |
| Write It in English (입문 2권) | Build Three Paragraphs | INTRODUCTION · BODY 1 · BODY 2 · CONCLUSION — **네 문단** (영어) |
| 1단계 | 나의 하루 | 영어 3~4문장 |
| 2단계 | 읽은 이야기 다시 쓰기 | 영어 6문장 × 두 모양 |
| 3단계 | 짝의 글 고치기 | 영어 **두 문단** |
| 4단계 | 네 문단으로 쓰기 | INTRODUCTION · BODY 1 · BODY 2 · CONCLUSION — **네 문단** (영어) |
| 5단계 | 다섯 문단 논설문 | 영어 다섯 문단 |
| 6단계 | 출처 밝히고 마무리 | 요약 + 리포트 |

**입문 2권과 4단계의 도착점이 글자 그대로 같다.** 칸 이름까지 같다.
첫걸음은 그것의 한국어판이다.

즉 지적은 정확했고, 실제로는 더 심하다. 입문 트랙이 1~4단계를 압축해
먼저 다 해 버린다.

## 왜 이렇게 되었나

입문 트랙을 선수학습 그래프만 보고 따로 설계했다. 그래프를 따라가면
「짧게 알리는 글 → 설명글의 구조대로 쓰기」까지 자연스럽게 이어지는데,
그 끝이 마침 4단계가 목표로 삼은 지점이었다. 단계 쪽 사다리와 대조하지
않은 것이 원인이다.

## 무엇이 망가지는가

- 입문을 마친 학생에게 **1단계(영어 세 문장)는 퇴보**로 느껴진다.
- 4단계에 도착했을 때 **“입문에서 했던 것”**이 되어, 4단계가 실제로 새로
  가르치는 것(응집성·글쓰기 용어·조사)이 가려진다.
- 입문 2권의 도착점이 3단계보다 위라, **입문이 입문이 아니다.**

## 고칠 방향

입문의 몫은 둘뿐이다 — ① **글쓰기 낱말**(계획·초고·고쳐쓰기·독자·목적),
② **구조가 존재한다는 감각**. 쓰기는 1단계부터가 맞다.
그래서 입문의 도착점을 **한 문단**으로 내리고, 잘라낸 것은 버리지 않고
그 내용이 실제로 필요한 단계 앞으로 옮긴다.

### 첫걸음 (한국어) — 11쪽 → 9쪽

| 걸음 | 조치 | 까닭 |
|---|---|---|
| 0 글쓰기 낱말 | 유지 | 이후 모든 지시문의 전제 |
| 1 처음·중간·끝 | 유지 | |
| 2 설명글의 구조 | 유지 | |
| 3 중심 생각·세부 내용 | 유지 | 입문에서 가장 중요 |
| 4 구조 파악 (시간순·비교·원인결과·문제해결) | **5단계 앞으로 이동** | 5단계 「정보 글의 구조 파악하기」와 정면으로 겹침 |
| 5 생각 정리 | 유지 | |
| 6 짧게 알리는 글 | **새 도착점** | 다섯 문장을 한 문단으로 |
| 7 네 문단 쓰기 | **4단계 앞으로 이동** | 4단계 완성 과제와 같은 것 |

### Write It in English (영어) — 9쪽 → 7쪽

도착점을 Practice 4(다섯 문장 한 문단)로 내리고 Practice 5(네 문단)를 뺀다.
다만 그래도 1단계(세 문장)보다 위이므로, **Practice 4의 산출을 세 문장으로
낮추어** 1단계와 같은 높이에서 만나게 한다. 소재가 다르므로 반복 연습이 된다.

### 옮긴 두 쪽의 새 자리

- **4단계 앞 한 쪽** — 한국어로 네 문단 세워 보기 (옛 걸음 7)
- **5단계 앞 한 쪽** — 한국어로 글의 구조 이름 붙이기 (옛 걸음 4)

입문 트랙을 “1단계 앞에 몰아 두는 두 권”에서 **“필요한 단계 앞에 붙는
한국어 예습”**으로 일부 옮기는 것이다. 모국어로 구조를 먼저 본다는 원래
설계 의도를 단계마다 살리는 방법이기도 하다.

## 대가

- 첫걸음 11 → 9쪽, Write It 9 → 7쪽. 4·5단계가 각 1쪽 늘어난다.
- 설계도의 입문 트랙 설명과 차례, 두 책의 표지 차례를 함께 고쳐야 한다.
- 이미 첫걸음을 끝까지 진행한 학급이 있다면 4단계에서 겹침을 겪는다.
  그 경우 4단계 완성 과제를 조사 기반으로만 남기고 네 문단 연습은 건너뛴다.

**아직 실행하지 않았다.** 승인 뒤 진행한다.
