# 워크시트 시리즈 기획서

## 1. 이 시리즈가 푸는 문제

한국어 화자 초등학생에게 **영어**와 **구조적 글쓰기**를 동시에 가르칠 때 생기는 근본 문제:

> **구조를 이해하는 능력이 영어 산출 능력보다 항상 앞서간다.**

초3 학생은 한국어로 "문단은 하나의 생각"을 이해할 수 있지만, 영어로는 3문장 쓰기도 벅차다.
여기서 두 가지 실패가 나온다 — 영어 수준에 구조를 맞추면 구조를 못 배우고,
구조 수준에 영어를 맞추면 아이가 무너진다.

**해결 원칙: 두 부하를 분리한다.**

- 구조 이해 = 한국어로 (지시문·교사 설명)
- 구조 조작 = 영어 지문으로, **쓰기 없이** (순서 배열·문장 골라내기)
- 영어 산출 = 비계(문장 틀·워드뱅크)로 낮춘 난이도에서

## 2. 이중 진행 (Dual Progression)

두 축이 **다른 속도로** 올라간다.

| | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 | 6단계 |
|---|---|---|---|---|---|---|
| **구조 축** | 처음·중간·끝 | 목적별 글 | **문단** | 3단 구조 | 근거·독자 | 요약·레이아웃 |
| **영어 축** | 단문 3개 | 문장 5~6개 | 한 문단 | 세 문단 | 네댓 문단 | 리포트+요약 |
| **문법 범위** | 현재/과거 단순 | 시간연결어·명령형 | 주제문 틀 | 대명사·because | 격식/비격식 | 패러프레이즈 |

## 3. 모든 워크시트가 따르는 4단 흐름

시리즈 전체가 같은 순서를 반복해, 학생이 **활동 방식 자체를 학습 부담으로 느끼지 않게** 한다.

| | 단계 | 하는 일 | 영어 산출 |
|---|---|---|---|
| 1 | **보기** SEE | 영어 본보기 글에서 구조 확인 | 없음 (읽기만) |
| 2 | **나누기** SORT | 순서 배열, 어울리지 않는 문장 찾기, 문단 나눌 자리 표시 | **없음** ← 핵심 |
| 3 | **채우기** FRAME | 문장 틀 + 워드뱅크로 부분 산출 | 부분 |
| 4 | **짓기** BUILD | 자유 산출 + 자기 점검 | 전체 |

**SORT가 이 설계의 핵심이다.** 영어를 한 글자도 쓰지 않고 구조 이해도를
확인·훈련할 수 있는 유일한 구간이라, 영어 실력이 병목이 되는 것을 막아 준다.

## 4. 한국어/영어 사용 규칙

| 요소 | 1~2단계 | 3~4단계 | 5~6단계 |
|---|---|---|---|
| 지시문 | 한국어 | 한국어 + 영어 병기 | 영어 (한국어 각주) |
| 지문·본보기 | **영어** | 영어 | 영어 |
| 학생 산출 | **영어** | 영어 | 영어 |
| 「선생님께」 | 한국어 | 한국어 | 한국어 |

지시문만 서서히 영어로 넘어간다. 산출은 처음부터 끝까지 영어다.

## 5. 고정 언어 비계 3종

매 워크시트에 항상 들어간다.

- **Word Bank** — 신호어를 기능별로 (시간순/추가/이유/대조/예시). 보고 베끼는 것 허용
- **Sentence Frames** — `I want to tell you about ___.` 문법에 막혀 구조를 못 배우는 상황 차단
- **Model Text** — 학생이 흉내 낼 완성 예시 한 편

## 6. 반복 소재 (Recycling)

전 단계에 걸쳐 **같은 소재 6개를 돌려 쓴다.**

```
my pet · our town · my favourite food · a season · a school day · an animal I know
```

단계가 올라가도 어휘를 새로 배우지 않고 **구조만 바뀌므로**, 어휘가 리셋되지 않고
누적된다. 초3에서 쓴 "my dog Kongi" 문단이 초5에서 근거를 갖춘 글로 자란다.

등장인물도 재사용한다 — 강아지 Kongi(2단계 → 3단계 → 4단계), 고양이 Nabi(3단계).

## 7. 단계별 스펙

| 단계 | 대상 | 구조 목표 | 산출 목표 | 대표 활동 |
|---|---|---|---|---|
| **1** | 초1 | 처음·중간·끝 | 영어 단문 3개 | 그림 순서 배열 → First/Then/Finally 3문장 |
| **2** | 초2 | 목적이 형식을 바꾼다 | 5~6문장 한 덩이 | 같은 소재를 recount와 instructions 두 형식으로 |
| **3** ★ | 초3 | **한 문단 = 한 생각** | 주제문+뒷받침 2~3 | 어울리지 않는 문장 찾기, 문단 나눌 자리 표시 |
| **4** | 초4 | 서론-본론-결론 + 응집성 | 3문단 | 막연한 단어→생생한 단어 교체 |
| **5** | 초5 | 독자에 맞춘 형식 + 근거 | 4~5문단 | 같은 내용을 친구용/선생님용 두 버전으로 |
| **6** | 초6 | 요약·레이아웃·출처 | 리포트+요약문 | 원문 1/3로 줄이기, 소제목·표 |

★ 3단계가 전환점. 여기서 문장이 문단으로 묶이지 않으면 이후가 모두 무너진다.

## 8. 물리 규격

- A4 인쇄
- **한 단계 = 4개 챕터 · 15장** (표지 1 + 워드뱅크 1 + 챕터 4×3 + 완성과제 1)
- 한 챕터 ≈ 2차시, 한 단계 ≈ 10차시
- 각 장 하단 **「선생님께」** — 정답 + 확인 기준 + 막힐 때 던질 질문 (한국어)

## 9. 자료 구성

```
글쓰기 첫걸음 (한국어, 입문 8걸음)
        ↓
Write It in English (입문 내용을 영어로)
        ↓
1단계 → 2단계 → 3단계 ★ → 4단계 → 5단계 → 6단계
        ↑
   수업 운영 노트 (교사용 · 차시 계획 + 진단 기록 + 처방)
```
