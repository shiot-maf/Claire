# 아티팩트 주소록

저장소가 원본이고 아티팩트는 그 사본이다. 고칠 곳은 늘 `src/` 쪽이며,
`python3 build.py` 로 만든 `worksheets/*.html` 을 아래 주소에 다시 올린다.
**새 주소를 만들지 말 것** — 같은 파일을 같은 주소에 다시 올려야 링크가 유지된다.

목록 페이지는 갤러리에서 지워졌다(2026-08-27). 링크 모음이 다시 필요하면 이 문서가
그 자리를 대신한다.

## 다시 올린 날 · 2026-08-27

열한 개를 모두 다시 올렸다. 말투를 손본 것(AI 같은 문장을 걷어낸 것)과
그동안 밀려 있던 공용 CSS 수정 — 차례 이름표 칸 정렬, 챕터 이름표 너비 맞추기,
한국어 어절 안 끊기 — 이 한꺼번에 반영되었다.

아티팩트를 올릴 때는 **같은 주소에 다시 올린다.** 새 주소를 만들면 설계도와
이 문서의 링크가 모두 끊긴다.
